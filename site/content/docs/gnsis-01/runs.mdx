---
title: "Runs and receipts API"
description: "The separate GNSIS 01 API for repository runs, evidence, approvals and receipts."
---

GNSIS 01 is the **always-on realtime perception system** described in the [perception and runtime overview](/docs/gnsis-01/perception). This page covers an additional, distinct GNSIS 01 capability: its run-oriented API for coding-agent executions over connected repositories.

This API is separate from Panoptic's visual-perception API. Do not treat Panoptic and GNSIS 01 as components of one product or infer that their sessions, credentials, or execution flows are interchangeable.

```bash
curl -sS -X POST https://api.gnsis.studio/v1/runs \
  -H "Authorization: Bearer $GNSIS_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: sample-run-001" \
  -d '{"repository_id":"repo_abc123","instruction":"Harden authentication middleware"}'
```

Use `GET /v1/runs/{run_id}/events` to follow progress and `GET /v1/runs/{run_id}/receipt` for evidence and accounting. Approvals remain explicit and scope-gated.

See the complete [GNSIS public API contract](https://github.com/aubincorinaldiecooper-bit/GNSISBACKEND/blob/main/docs/public_api.md) for scopes, pagination, error codes and related endpoints.
