---
title: "Authentication and trust"
description: "Workspace API keys, grants and planner session tokens."
---

A GNSIS workspace key scoped to `visual:host` exchanges for a short-lived runtime grant at `POST https://api.gnsis.studio/v1/visual/grants`.

The **host** uses this grant to open sessions. Session creation returns separate credentials:

- **Stream token**: host-controlled frame ingestion.
- **Planner token**: read and plan within exactly one session.
- **Workspace virtual key**: kept by your application, never sent to an agent.

A planner credential cannot create or close a session or record action attempts. The trusted host is the only component authorized to capture the stream, enforce confirmations, execute actions and verify results.

Use HTTPS for non-loopback connections, and never commit credentials into documentation or examples.
