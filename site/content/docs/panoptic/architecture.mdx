---
title: "Trust and visual architecture"
description: "Continuous perception and the trusted-host action boundary."
---

The host supplies a **persistent rolling video stream** to Panoptic. The service maintains bounded temporal context, describes visible state and produces an optional next-action proposal.

An action proposal is tied to a specific frame generation. The trusted host compares the proposal with the current frame, applies its own policy and any user confirmation, then executes or rejects it. The ongoing stream provides subsequent observation and verification.

This is not a screenshot polling architecture. Panoptic does not own display capture, DOM inspection, OS input or user credentials.

The complete source-level contract is maintained in [Panoptic service guide](https://github.com/aubincorinaldiecooper-bit/GNSISBACKEND/blob/main/docs/smaller-gnsis-service.md).
