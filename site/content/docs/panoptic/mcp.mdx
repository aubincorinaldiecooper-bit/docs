---
title: "MCP server"
description: "Connect AI agents to a host-owned Panoptic visual session."
---

The optional Python SDK extra installs the local stdio MCP adapter `panoptic-mcp`.

```bash
pip install "gnsis-visual-sdk[mcp] @ git+https://github.com/aubincorinaldiecooper-bit/GNSISBACKEND.git#subdirectory=sdks/python"
```

A trusted host must create a visual session first. Configure your MCP process with the **planner token** and session ID:

```dotenv
GNSIS_VISUAL_API_BASE=https://visual.example
GNSIS_VISUAL_API_TOKEN=<session-planner-token>
GNSIS_VISUAL_SESSION_ID=<host-created-session>
GNSIS_VISUAL_CLIENT=my-agent/1.0
```

Run `panoptic-mcp` as a stdio server.

| Tool | Purpose |
| --- | --- |
| `visual_perceive` | Describe the current screen, including pixel-grounded focus |
| `visual_state` | Read current frame, task, history and usage |
| `visual_history` | Read bounded visual history |
| `visual_inspect` | Inspect a retained image region |
| `visual_read_pixels` | Read exact pixel colours |
| `visual_set_task` | Set a goal and allowable actions |
| `visual_decide` | Propose an action but never execute |
| `visual_reset` | Clear task/action history |

The adapter has **no screen capture, session-creation, click, or arbitrary-execution tools**. Tokens are session-scoped, so new sessions require new planner credentials.

See the [maintained adapter configuration for Claude Code, Codex and OpenClaw](https://github.com/aubincorinaldiecooper-bit/GNSISBACKEND/blob/main/docs/smaller-gnsis-service.md#mcp-adapter).
