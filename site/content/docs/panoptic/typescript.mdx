title: "TypeScript SDK"
description: "Use the @gnsis/visual-sdk client from a trusted host."
---

The TypeScript package is named `@gnsis/visual-sdk` and its source lives at [GNSISBACKEND/sdks/typescript](https://github.com/aubincorinaldiecooper-bit/GNSISBACKEND/tree/main/sdks/typescript).

Build from source as needed; the source repository does not establish that this package is published to npm.

```ts
import { VisualClient, FrameStream } from '@gnsis/visual-sdk';

const host = new VisualClient({
  baseUrl: process.env.PANOPTIC_API_BASE!,
  apiToken: process.env.GNSIS_VISUAL_HOST_TOKEN!,
});
const session = await host.createSession();
const planner = new VisualClient({
  baseUrl: process.env.PANOPTIC_API_BASE!,
  apiToken: session.plannerToken,
});
try {
  await planner.setTask(session.sessionId, 'Find the requested control', ['click']);
  const proposal = await planner.decide(session.sessionId);
  // Only your trusted host can approve and execute the proposal.
} finally {
  await host.closeSession(session.sessionId);
}
```

For streaming, call `FrameStream.connect` and continuously send frames originating from the trusted host.

See the [full TypeScript SDK examples](https://github.com/aubincorinaldiecooper-bit/GNSISBACKEND/blob/main/sdks/typescript/README.md).
