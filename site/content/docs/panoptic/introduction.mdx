---
title: "Panoptic overview"
description: "Persistent visual perception for agents and trusted computer-use hosts."
---

Panoptic consumes an ongoing stream of frames from a trusted browser or desktop host. It describes the current scene, text, locations, changes and optionally proposes one next action from an allowed set.

The trusted host owns the visual capture, permissions, confirmation, execution and post-action verification.

**Persistent stream → agent perception or bounded decision → host-authorized action → ongoing visual verification.**

Panoptic does **not** inspect DOM selectors, cookies or credentials. It does not repeatedly request screenshots or execute actions on the host.

Continue with [Quickstart](/docs/panoptic/quickstart) or the [MCP guide](/docs/panoptic/mcp).
