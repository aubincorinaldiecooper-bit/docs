title: "Quickstart"
description: "Create a Panoptic session, stream frames and ask the agent what is visible."
---

## 1. Get access

Request a key at https://gnsis.studio/developers/panoptic. You receive a workspace API key scoped to `visual:host` and the URL of your Panoptic visual runtime.

## 2. Exchange the key for a short-lived host grant

```bash
curl -sS -X POST https://api.gnsis.studio/v1/visual/grants \
  -H "Authorization: Bearer $GNSIS_API_KEY"
```

Take the `grant` field from the response. Do not share your long-lived workspace key with an agent.

## 3. Create a visual session

```bash
curl -sS -X POST "$PANOPTIC_API_BASE/v1/visual/sessions" \
  -H "Authorization: Bearer $PANOPTIC_GRANT"
```

The response returns a `session_id`, a host-only stream token and a session-scoped planner token.

## 4. Start the persistent visual stream

The trusted host connects to the returned WebSocket stream path using its stream token. Each visual update has a `screen.frame` JSON header followed by a JPEG, WebP or PNG binary frame. Use the [Python](/docs/panoptic/python) or [TypeScript](/docs/panoptic/typescript) SDK to integrate this with your host.

## 5. Read or plan

Use the **planner token** to call `POST /v1/visual/sessions/{session_id}/perceptions` to ask what is visible, without defining a task.

To get a bounded action proposal, use `PUT /v1/visual/sessions/{session_id}/task` and then `POST /v1/visual/sessions/{session_id}/decisions`. The trusted host must check the frame, permission and approval policy before acting.

Close the session from your host when finished. See [HTTP API reference](/docs/api-reference).
