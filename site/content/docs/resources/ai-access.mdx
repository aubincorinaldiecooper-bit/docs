This documentation website exposes:

- [llms.txt](/llms.txt), the documentation index for agents.
- [llms-full.txt](/llms-full.txt), a combined Markdown representation.
- Individual Markdown pages by appending `.md` to a documentation URL.

The **Panoptic MCP product adapter** provides session perception and planning; it is distinct from a documentation-reading MCP service. See [MCP guide](/docs/panoptic/mcp).
