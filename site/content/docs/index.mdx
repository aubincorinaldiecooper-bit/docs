# Build with GNSIS

**Panoptic** gives AI agents persistent visual perception over a stream owned by a trusted host. It understands what is on screen, what changed, and can propose one bounded next action. It does not capture screens or execute actions.

**GNSIS 01** exposes a separate API for repository coding runs, execution evidence and approvals.
