title: "Panoptic HTTP API"
description: "Generated, interactive endpoint reference for the Panoptic visual runtime."
---

Pages in **Endpoints** are generated from the checked-in Panoptic OpenAPI contract during `npm run build`. That contract is a **curated snapshot** of the implemented FastAPI routes, not an automatically exported backend schema.

The reference covers the HTTP session lifecycle, perception, decisions, history, inspections and pixels.

The binary frame stream uses WebSocket and therefore is described in the [quickstart](/docs/panoptic/quickstart), not as an HTTP endpoint.

The workspace grant exchange `POST https://api.gnsis.studio/v1/visual/grants` belongs to the **control plane**, not this visual runtime. Read [authentication](/docs/panoptic/authentication).

The interactive playground requires a reachable runtime and a valid credential. Use your own assigned endpoint; never publish host credentials.
